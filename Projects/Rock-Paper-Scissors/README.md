# Rock Paper Scissors

A simple Rock-Paper-Scissors game built using HTML, CSS, and JavaScript.

## Features

- Player can choose Rock, Paper, or Scissors
- Computer generates a random choice
- Winner is determined based on the game rules
- Player and computer scores are updated after each round
- Displays both choices and the result of each round

## Technologies Used

- HTML
- CSS
- JavaScript

## JavaScript Concepts Practiced

- DOM Manipulation
- Event Listeners
- Functions
- Function Parameters
- Return Values
- `Math.random()`
- Conditional Statements
- Variables and State
- `textContent`

## Game Logic

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie
